## Features

<CardGrid>
  <Card title="Results instead of exceptions" icon="approve-check">
    Every call returns a Result: the success data, a documented error body, an undocumented status, or a network failure. Each case has its type.
  </Card>
  <Card title="A single binary" icon="rocket">
    The generator is written in Rust and needs no Node to generate. npm installs the binary for macOS, Linux or Windows (x64 and arm64).
  </Card>
  <Card title="Thin, strict output" icon="seti:typescript">
    Generated code passes TypeScript's strictest options and is checked against real-world definitions in CI. Serialization lives in a small runtime library.
  </Card>
  <Card title="TanStack Query, Zod and mocks" icon="puzzle">
    Optionally generates TanStack Query options, Zod schemas, and sample data with MSW handlers for UI development and tests.
  </Card>
  <Card title="TypeScript, Python, Rust and Go" icon="translate">
    TypeScript and Python, with Rust and Go experimental. Backends for other languages can live in their own repositories.
  </Card>
  <Card title="For coding agents" icon="laptop">
    An MCP server and a JSON CLI answer which function calls an endpoint and how to call it. [llms.txt](llms.txt) lists the documentation.
  </Card>
</CardGrid>
