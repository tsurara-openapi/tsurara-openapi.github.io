# CLAUDE.md

This repository is the website of [tsurara](https://github.com/tsurara-openapi/tsurara): a home page and the documentation in English, Japanese and Simplified Chinese, built with Astro and Starlight and deployed to GitHub Pages.

## Commands

Toolchain versions are pinned in `mise.toml`; run tools through mise (`mise exec -- pnpm ...`).

```
pnpm install
pnpm dev                 # local server
pnpm build               # dist/
pnpm sync [path]         # copy the English docs from a tsurara checkout (default ../tsurara)
pnpm translations        # list missing and stale translations (after a build, also heading ids)
node scripts/check-translations.mjs --ids guide/client   # English headings and ids of a page
```

## Where things come from

- The English pages (`src/content/docs/*.md` and the directories `guide/`, `languages/` outside `ja/` and `zh-cn/`) are written by `scripts/sync-docs.mjs` from tsurara's `README.md`, `docs/guide/`, `docs/languages/` and `docs/design.md`. Never edit them here: change them in tsurara and sync. `tsurara.json` records the synced commit.
- `public/llms.txt` and `public/llms-full.txt` are copied by the sync too.
- `samples/out/` is generated by the sync with the tsurara binary of the checkout (build it first). The home page (`src/components/Samples.astro`) shows those files; its usage snippets are written by hand and must match the generated API.
- The home pages `src/content/docs/index.mdx`, `ja/index.mdx` and `zh-cn/index.mdx` are written here.

## Dependencies

As in tsurara, a dependency version must have been released at least 5 days earlier (`minimumReleaseAge` in `pnpm-workspace.yaml`, Dependabot's `cooldown`). Actions are pinned by commit with the version in a comment.

## Translations

Every English page has a translation in `ja/` and `zh-cn/` at the same path.

- Frontmatter: translate `title`; copy `sourcePath` and `sourceHash` from the English page the translation was made from. When the English page changes, `sourceHash` changes and `pnpm translations` lists the translation as stale: update the text, then the hash.
- Headings: every translated heading ends with the id of the English heading, `## 結果 {#results}` (`node scripts/check-translations.mjs --ids <page>` lists them). Links with anchors then work in every language.
- Keep code blocks, inline code, configuration keys, identifiers, file names, URLs and link targets exactly as in English. Translate code comments only when they are prose for the reader; keep the comment out when unsure.
- Keep tables with the same rows and columns. Translate the prose cells.
- Keep references such as `design.md 18.7`, `Q3` and `pass 10` as written.
- Translate the meaning, not the English sentence structure. Write what the English says, no more and no less: do not add explanations, and keep numbers, conditions and negations as they are.
- Japanese: です・ます for the guides and language pages, だ・である for `design.md`. No spaces between Japanese and Latin text. Full-width parentheses around Japanese text（このように）, half-width ones around code only.
- Simplified Chinese: a half-width space between Chinese and Latin text or numbers. Full-width punctuation（，。：；（））in Chinese sentences.
