# tsurara-openapi.github.io

The website of [tsurara](https://github.com/tsurara-openapi/tsurara) at https://tsurara-openapi.github.io/, in English, Japanese and Simplified Chinese. Built with [Astro](https://astro.build) and [Starlight](https://starlight.astro.build), deployed to GitHub Pages by `.github/workflows/deploy.yml`.

```sh
mise install
pnpm install
pnpm dev
```

The English documentation comes from the tsurara repository (`pnpm sync`); see [CLAUDE.md](CLAUDE.md) for how the pages and translations are organized.
